근차(Geuncha) Windows 개발 테스트 버전

이 설치 파일은 Windows 10 22H2 이상 또는 Windows 11의 x64 환경을 대상으로 합니다.
Node.js, MariaDB 실행 파일과 앱 및 필요한 JavaScript 패키지를 포함합니다.
개발 도구나 Node.js를 별도로 설치할 필요가 없습니다.
Microsoft Visual C++ 런타임이 없는 PC에서는 공식 Microsoft 설치 관리자가 실행되며 관리자 권한 승인이 필요할 수 있습니다.

설치 후 시작 메뉴의 Geuncha를 실행하면 PC별 무작위 DB 비밀번호와 새 로컬 DB를 만들고 브라우저를 엽니다.
기존 .env 설정, DB 데이터, 업로드는 업데이트 시 덮어쓰지 않습니다. 삭제 후에도 해당 데이터는 설치 폴더에 남습니다.
다른 PC로 현재 PC의 회원·예약 데이터를 자동 복사하거나 동기화하지 않습니다.

개발 게스트: guestdemo
개발 호스트: hostdemo
개발 계정 공통 비밀번호: Geuncha123!

이 버전의 인증·결제·보험·외관 AI·계좌 지급은 실제 운영 공급자와 연결되어 있지 않습니다.
인터넷 없이 설치·로컬 실행할 수 있지만 지도 타일 및 외부 서비스에는 인터넷 연결이 필요합니다.
Geuncha Mobile Test 바로가기는 같은 공유기에 연결된 휴대폰 브라우저 테스트용입니다.
일반 LAN HTTP 접속에서는 휴대폰 GPS 인증에 제한이 있습니다.

실행 중인 창을 유지하세요. 오류 기록은 .runtime\startup.log에 남습니다.
설치 프로그램은 다른 프로그램의 Node.js·MariaDB 또는 Windows 방화벽 설정을 변경하지 않습니다.
