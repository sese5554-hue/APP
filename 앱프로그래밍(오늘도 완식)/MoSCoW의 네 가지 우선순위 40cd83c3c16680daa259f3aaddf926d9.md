# MoSCoW의 네 가지 우선순위

<aside>
🎯

**우선순위 기준**

핵심 목적은 유통기한을 미리 알려 상하기 전에 레시피로 식재료를 소진하도록 돕는 것입니다.

</aside>

## Must have · 필수

- 식재료 CRUD (등록/조회/수정/삭제)
- 유통기한 D-Day 자동 계산 및 D-Day순 정렬
- D-Day 푸시 알림 (D-3, D-1)
- 임박 재료 기반 레시피 추천 (공공 API)

없으면 이번 제품의 핵심 목적 달성 불가. 앱의 존재 이유이자 시연 필수 기능입니다.

## Should have · 중요

- 보관 장소별 (냉장/냉동/실온) 탭 구분 UI
- 소진 완료 시 1클릭 재구매 제휴 링크 연동

임시 대안으로 핵심 흐름을 유지할 수 있습니다. 보관 장소 구분 없이 단일 리스트로 확인할 수 있고, 재구매 링크가 없어도 사용자가 직접 마트나 앱에서 장을 볼 수 있습니다.

## Could have · 여유 시

- 식재료별 기본 유통기한 자동 입력 지원
- 카테고리/이름 검색 및 필터링 기능
- 영수증 OCR 촬영 자동 입력 기능

핵심 흐름 확인 후 시간이 남으면 추가합니다. 수동 입력만으로도 기본 기능은 작동하므로 10~14주차 메인 기능 완성 후 진행합니다.

## Won’t have this time · 이번 제외

- 이웃 간 식재료 나눔 커뮤니티
- 소셜 로그인 (카카오/구글 등 연동)
- 인앱 유료 결제 모듈 연동
- AI 기반 1:1 맞춤 식단 추천
