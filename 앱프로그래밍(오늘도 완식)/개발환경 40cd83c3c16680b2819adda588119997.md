# 개발환경

<aside>
🧰

**개발 스택 흐름**

Flutter / Dart → Node.js / Express → MariaDB → AWS Lightsail

</aside>

## 프론트엔드 · Flutter

- **개발 툴 (IDE):** VS Code (또는 Android Studio) — Flutter / Dart 확장 프로그램 연동
- **프레임워크/SDK:** Flutter SDK (Stable 버전) — Cross-Platform App 개발 (Dart 언어)
- **실행/테스트 디바이스:** Android Emulator 또는 실물 모바일 기기 — USB 디버깅 연동 테스트 (macOS 시 iOS Simulator 가능)

## 백엔드 · Node.js

- **런타임 / 프레임워크:** Node.js (LTS 버전) + Express.js — RESTful API 서버 구축 및 통신 처리
- **API 테스트:** Postman (또는 Bruno) — 백엔드 API HTTP 요청/응답(JSON) 검증

## 데이터베이스 · MariaDB

- **DB 엔진 / 클라이언트:** MariaDB + DBeaver (또는 HeidiSQL) — 관계형 데이터베이스 관리 및 테이블 시각화 툴

## 서버·인프라 · AWS

- **서버 호스팅:** AWS Lightsail (Ubuntu Linux) — 고정 요금제 인스턴스 구축 ($3.5~$5/월)
- **원격 관리 툴:** SSH (터미널/Git Bash) + PM2 — 리눅스 서버 접속 및 Node.js 무중단 실행 관리
