# 인수 조건과 실행 상태

**검증 범위**

정상 등록 · 잘못된 입력 · 소진 상태 변경 · 빈 상태, 네 가지 상황으로 핵심 흐름을 확인합니다.

| **조건** | **행동과 기대 결과** | **확인 방법** |
| --- | --- | --- |
| **정상** | **식재료 정상 등록**

식재료명 '계란', 보관장소 '냉장', 유통기한 'D+3일' 선택 후 저장 ➔ 메인 '냉장' 탭 목록에 '계란' 추가 및 `D-3` 정확히 표시 | • '냉장' 탭 리스트에 항목 추가 여부 시각적 확인

• D-Day 자동 계산값(`D-3`) 표시 및 전체 항목 수(+1) 증가 확인 |
| **잘못된 입력** | **식재료명 공백 제출**

식재료명을 빈칸(공백)으로 둔 채 '저장' 버튼 클릭 ➔ "식재료 이름을 입력해 주세요" 경고 메시지 노출 및 저장 거부 | • 하단 스낵바/안내 문구 노출 확인

• DB 저장 요청 미발생 및 기존 목록 수 변경 없음 확인 |
| **상태 변경** | **소진 완료 선택**

'계란' 항목의 '소진 완료' 스위치 토글 ➔ '계란'만 완료 처리되어 활성 리스트에서 제거되고 재구매 팝업 노출 | • '계란' 항목만 상태 변경 확인

• 함께 등록된 다른 식재료('우유' 등)의 D-Day 및 상태가 유지되는지 비교 |
| **빈 상태** | **등록된 식재료 없음**

냉장고에 등록된 식재료가 0개인 상태로 앱 진입 ➔ "냉장고가 비어있어요! 아래 + 버튼으로 식재료를 채워보세요" 빈 화면 안내 노출 | • 최초 로그인 또는 전체 식재료 소진 후 메인 화면 확인

• 엠프티 뷰(Empty View) 안내 문구 및 추가 유도 버튼 노출 확인 |
