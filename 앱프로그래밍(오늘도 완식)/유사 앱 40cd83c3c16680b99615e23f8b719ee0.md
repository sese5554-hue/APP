# 유사 앱

<aside>
🔎

냉장고 식재료를 관리하고, 소비기한을 확인하며, 보유 재료로 요리를 추천하는 앱을 기획하기 위한 유사 앱 조사입니다.

관찰 내용을 바탕으로 우리 앱에 참고할 UX와 추가 확인이 필요한 항목을 정리했습니다.

</aside>

## 🔎 한눈에 비교

| 앱 | 핵심 경험 | 참고할 점 |
| --- | --- | --- |
| eggg (에그) | 식재료 카드 관리와 보유 재료 기반 레시피 추천 | 카드에서 유통기한을 빠르게 확인하고, 재료 소진을 간편하게 처리 |
| 프리지 (Fridgi) | 영수증 스캔 등록, 보관 장소별 관리, 임박 알림 | 보관 타입별 탭과 여러 재료의 일괄 처리 |

### 🥚 eggg (에그)

**앱 정보**

- [App Store에서 보기](https://apps.apple.com/kr/app/id6532580810)
- 확인 날짜: 2026년 11월 2일

**직접 관찰**

- **화면:** 냉장고 재고 카드 목록, 식재료 상세(메모·유통기한·추가일), 보유 재료 기반 AI 레시피 탭
- **행동:** 식재료를 좌우로 밀어 삭제하거나 메모를 추가하고, 재료를 선택해 레시피 제안을 요청
- **결과:** 요리 단계별 레시피가 표시되고, 부족한 재료를 추가로 확인할 수 있음

**비교 판단**

- **좋았던 점:** 식재료별 메모(최대 40자), 직관적이고 감각적인 카드형 UI
- **불편했던 점:** 보유 수량을 세분화해 차감하기 어렵고, 신선식품의 소비기한 자동 제안이 맞지 않을 때 수정이 번거로움
- **우리 앱에 참고:** 카드에서 소비기한 D-Day를 바로 보여주고, 재료를 소진하면 목록에서 자연스럽게 정리되는 흐름

### 🧊 프리지 (Fridgi)

**앱 정보**

- [App Store에서 보기](https://apps.apple.com/kr/app/id6760248261)
- 확인 날짜: 2026년 11월 2일

**직접 관찰**

- **화면:** 영수증 OCR 촬영 화면, 냉장·냉동·실온별 탭, D-Day 카운트다운 목록
- **행동:** 영수증을 인식해 재료를 한 번에 등록하고, 길게 눌러 여러 항목을 선택해 삭제하거나 소비 처리
- **결과:** D-7·D-3·D-Day 푸시 알림을 받고, 소비기한이 임박한 재료를 바탕으로 요리 추천을 확인

**비교 판단**

- **좋았던 점:** 보관 장소별로 재료를 찾기 쉽고, 여러 항목을 한 번에 처리할 수 있음
- **불편했던 점:** 영수증에 비식품이나 브랜드명이 포함되면 인식 결과를 사용자가 직접 수정해야 함
- **우리 앱에 참고:** 냉장·냉동·실온 보관 탭과 D-3·D-1 묶음 알림 설정

## 💡 우리 앱 기획에 적용할 점

1. **소비기한을 한눈에:** 재료 카드에 D-Day를 눈에 띄게 표시하고, 임박·오늘·만료 상태를 색이나 배지로 구분합니다.
2. **보관 장소별 탐색:** 냉장·냉동·실온을 분리해 재료를 빠르게 찾을 수 있도록 합니다.
3. **간편한 소진 처리:** 재료 수량을 조절하거나 소비 완료로 표시하면 메인 목록에서 즉시 정리되도록 합니다.
4. **알림 시점 선택:** D-3·D-1 등 알림 시점을 사용자가 설정할 수 있게 합니다.
5. **등록 결과 수정 지원:** 직접 입력이나 영수증 인식 결과를 쉽게 확인·수정할 수 있도록 합니다.
6. **재료 기반 레시피 연결:** 소비기한이 임박한 재료를 우선 활용하는 요리를 제안합니다.
