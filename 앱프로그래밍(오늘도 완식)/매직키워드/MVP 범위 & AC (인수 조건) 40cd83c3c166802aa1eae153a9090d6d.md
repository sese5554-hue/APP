# MVP 범위 & AC (인수 조건)

<aside>

## ✅ AC · 인수 조건

## AC-01 · 식재료 등록 및 D-Day 계산

- **Given:** 사용자가 로그인 후 식재료 등록 화면에 진입하여
- **When:** 식재료명(예: 계란)과 유통기한 날짜를 선택하고 저장 버튼을 누르면
- **Then:** MariaDB에 데이터가 저장되고, 메인 화면 리스트에 `D-OO` 형태로 잔여일이 자동 계산되어 D-Day가 적은 순서대로 정렬되어야 합니다.

## AC-02 · 유통기한 임박 알림

- **Given:** 등록된 식재료의 유통기한이 D-3일 이하가 되면
- **When:** 지정된 알림 시간(예: 오전 9시)이 되었을 때
- **Then:** 모바일 기기 상단에 “계란의 유통기한이 3일 남았습니다!” 푸시 알림이 정상 수신되어야 합니다.

## AC-03 · 남은 재료 레시피 추천

- **Given:** 메인 화면에서 유통기한 임박 식재료를 클릭하고 '레시피 보기'를 누르면
- **When:** 백엔드 서버가 공공데이터 레시피 API를 호출할 때
- **Then:** 해당 식재료를 재료 목록에 포함하고 있는 요리 레시피 카드 목록이 정상적으로 화면에 출력되어야 합니다.

## AC-04 · 식재료 소진 및 재구매 연동

- **Given:** 레시피를 보고 요리를 마친 사용자가 식재료 항목의 '소진 완료' 스위치를 켜면
- **When:** 식재료가 메인 리스트에서 제거됨과 동시에
- **Then:** “재구매하시겠습니까?” 팝업과 함께 쿠팡 파트너스 구매 제휴 링크 버튼이 노출되어야 합니다.
