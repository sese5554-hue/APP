# Google AI Mode(dart파일 구현)

Google AI(Gemini 등)를 활용하여 프로젝트의 전체적인 **구조(목차)**를 잡고, 각 Dart 파일의 역할과 연결 관계를 정의하는 **'매핑 사전'**을 먼저 구축하면 대규모 앱도 손쉽게 구현할 수 있습니다.

AI와 함께 여러 Dart 파일로 앱을 분할하여 개발할 때 사용할 수 있는 **구조적 접근법(매핑 사전 가이드)**을 안내해 드립니다.

---

**🗺️ Flutter 다중 파일 개발을 위한 '매핑 사전' (구조 예시)**

프로젝트를 시작하기 전, AI에게 다음과 같은 **폴더 및 파일 구조(목차)**를 먼저 제안해 달라고 하거나, 직접 정의하여 AI에게 컨텍스트(문맥)로 제공해야 합니다. 가장 흔히 쓰이는 **기능 중심(Feature-based) 구조** 예시입니다.

**text**

```
lib/
├── main.dart                 # 앱의 시작점 (Theme 설정, 초기화, 라우팅 등록)
├── app_routes.dart           # [매핑 사전 1] 화면 이동(Routing) 경로 정의
├── models/                   # [매핑 사전 2] 데이터 구조 정의
│   ├── user_model.dart
│   └── product_model.dart
├── screens/                  # [매핑 사전 3] UI 화면들
│   ├── home/
│   │   ├── home_screen.dart  # 홈 화면 메인
│   │   └── widgets/          # 홈 화면에서만 쓰는 작은 컴포넌트
│   └── profile/
│       └── profile_screen.dart
└── widgets/                  # 공통 UI 컴포넌트 (버튼, 입력창 등)
    └── custom_button.dart
```

코드를 사용할 때는 주의가 필요합니다.

---

**🚀 Google AI 모드로 협업하는 3단계 순서**

AI에게 한 번에 "앱 전체 코드 짜줘"라고 하면 코드가 끊기거나 누락됩니다. 아래 순서로 나누어 요청하세요.

**1단계: 목차 및 매핑 사전 정의 요청 (설계)**

가장 먼저 어떤 앱을 만들고 싶은지 아이디어를 내고, 파일 구조를 짜달라고 합니다.

> **AI 프롬프트 예시:**"쇼핑몰 앱을 만들고 싶어. `main.dart` 하나에 다 넣지 않고 여러 Dart 파일로 분리할 거야. 서비스 규모에 맞는 `lib/` 폴더 구조(목차)와 각 파일의 역할을 정의해 줘."
> 

**2단계: 화면 전환(라우팅) 매핑 테이블 작성**

여러 파일로 갈라진 화면들을 서로 연결해 주는 '지도'를 만듭니다. Flutter에서는 `GoRouter`나 기본 `MaterialPageRoute`를 사용하여 라우팅 전용 파일을 만듭니다.

> **AI 프롬프트 예시:**"홈 화면(`home_screen.dart`)과 프로필 화면(`profile_screen.dart`)을 이동할 수 있는 `app_routes.dart` 파일을 작성해 줘. 그리고 `main.dart`에서 이 라우터를 어떻게 불러와야 하는지 연결 코드도 짜줘."
> 

**3단계: 파일별로 조각내어 구현 요청 (구현)**

지도가 완성되면, 목차에 있는 파일을 하나씩 짜달라고 요청합니다.

> **AI 프롬프트 예시:**"앞서 정의한 구조 중에서 `models/product_model.dart`와 이 모델을 활용해 상품 목록을 보여주는 `screens/home/home_screen.dart` 코드를 작성해 줘."
> 

**💡 AI 모드 활용 핵심 팁**

**`import` 문 챙기기:** 파일이 나누어지면 서로를 불러오는 `import 'package:프로젝트명/...';` 코드가 필수적입니다. AI에게 코드를 요청할 때 **"파일 분리에 필요한 import 구문도 생략 없이 정확하게 적어줘"**라고 명시하세요.
