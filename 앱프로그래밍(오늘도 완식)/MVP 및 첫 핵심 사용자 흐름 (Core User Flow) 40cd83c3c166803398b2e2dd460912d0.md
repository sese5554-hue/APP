# MVP 및 첫 핵심 사용자 흐름 (Core User Flow)

## 🧭 1. 첫 핵심 사용자 흐름 (Core Flow)

<aside>
🧭

**사용자가 식재료를 추가하고 유통기한 D-Day를 확인하며, 식재료 소진(완료)을 표시해 남은 식재료 항목 및 추천 레시피를 확인할 수 있으면 첫 핵심 흐름이 완성됩니다.**

</aside>

1. **식재료 추가 (Input):** 사용자가 장을 본 뒤 식재료 이름, 보관 장소(냉장/냉동/실온), 유통기한 날짜를 입력하여 냉장고에 등록합니다.
2. **남은 항목 & D-Day 확인 (Status Check):** 메인 화면에서 유통기한 임박순(D-Day)으로 정렬된 남은 식재료 리스트를 확인합니다.
3. **완료 표시 / 소진 처리 (Action):** 요리를 마치거나 재료를 다 썼을 때 해당 항목에 '소진 완료' 체크를 합니다.
4. **결과 확인 & 재구매 (Result):** 소진 처리 후 남은 식재료 목록이 즉시 업데이트되며, 소진된 재료의 1클릭 재구매 링크 팝업 또는 임박 재료 기반 추천 레시피를 확인합니다.

## 📱 2. 첫 핵심 흐름 구성을 위한 MVP 필수 화면 구성

```
[식재료 3초 등록 화면] ➔ [메인 냉장고 리스트 화면] ➔ [소진 완료 체크 & 레시피/재구매]
  (이름/장소/날짜 입력)     (D-Day 정렬 & 남은 항목)        (목록 갱신 & 외부 연동)
```

- **화면 1: 식재료 등록 폼 (Create)** - 필수 3개 값(이름, 보관 장소, 유통기한) 입력
- **화면 2: 메인 냉장고 목록 (Read & Delete/Update)** - 냉장/냉동/실온 탭 구분 및 D-Day 순 남은 항목 노출, 완료 체크 스위치
- **화면 3: 레시피 & 재구매 팝업 (Feature Connection)** - D-3 이하 임박 재료 기반 레시피 카드 및 소진 재료 재구매 링크
