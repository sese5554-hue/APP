단계 1 / 실행 기반과 MariaDB
- package.json, package-lock.json: Node.js/TypeScript, Express, React/Vite, MariaDB connector 및 실행/빌드/검증 명령.
- packages/contracts/index.ts: 로그인/가입/차량/예약/점검/후기 입력을 Zod로 검증하고 사용자·차량·예약 응답 타입을 공유.
- database/migrations/001_initial.sql: 사용자/세션/인증/차량/기간/예약/결제/채팅/점검/정산/후기/문의 등 관계형 테이블, FK·CHECK·고유 제약.
- apps/api/src/database/db.ts: 연결 풀·트랜잭션·UTC 변환. migrate.ts는 DB 잠금과 checksum으로 migration 적용 이력 보호. seed.ts는 개발용 두 역할 계정과 차량/보험/카드 생성, 중복 실행 보존.
- apps/api/src/domain/pricing.ts: 서버 단일 요금 계산, 허용 예약 상태 전이, 초과 주행료. lib/crypto.ts: native scrypt+무작위 salt 및 타이밍 안전 비교.
- scripts/start.mjs, env.mjs, process.mjs, portable-db.mjs, dev.mjs, start.cmd/start.sh, compose.yaml: 최초 환경 생성·의존성 설치·DB 준비·마이그레이션·시드·개발 프로세스 관리. Windows portable MariaDB는 공식 압축본을 SHA256 검증 후 .runtime에서 로컬 실행. 개발 DB는 종료해도 데이터 보존.
- 검증: API TypeScript 컴파일 검사 성공. 요금/주행료/상태 전이/비밀번호 테스트 4개 통과. MariaDB 압축본 다운로드 및 실제 DB 검증은 진행 중.
- SOLID: SQL/트랜잭션과 순수 요금 도메인 분리. KISS: 단일 서버+단일 DB와 SQL migration. YAGNI: 미요구 포인트/쿠폰/멀티서비스 제외.
- 이 커밋은 기반 단계이며 화면과 HTTP 서버 조립이 완료되기 전에는 전체 앱을 실행할 수 없음. 다음 커밋에서 인증과 UI 연결.

- 직접 실행으로 DB/API/Vite와 Chrome 로그인 화면 정상 시작을 확인하고, 두 번째 실행에서 Port 5173 is already in use 및 실패 종료 코드가 0이 되는 문제를 재현했다.
- scripts/launcher-health.mjs: 근차 HTML과 MariaDB health를 함께 확인하고 정상 인스턴스 재사용, 포트 충돌 진단, 제한 시간 내 준비 확인, 기본 브라우저 열기, 본인이 실행한 자식만 정리한다.
- scripts/start.mjs/start.cmd: 준비 완료 후 브라우저 자동 실행, 중복 실행 시 DB 작업 없이 기존 서버 사용, 단계별 오류·자식 로그를 .runtime/startup.log에 기록. --no-open은 QA용. 비밀번호·토큰은 로그에서 제거한다.
- scripts/dev.mjs: 종료 코드를 먼저 저장하고 타이머가 실행되기 전에 정상 코드로 빠져나가던 경로 수정. scripts/process.mjs: 자식 출력 전달/로그 저장/실제 종료 코드 전파. 사용자 .env와 DB 데이터 보존.
- Vite proxy는 .env의 실제 API PORT를 사용하되 NODE_ENV를 변경하지 않아 운영 빌드에 개발 React가 포함되지 않도록 분리.
- 회귀 검증: 실행 상태/타 앱 구별·대기 취소·포트 점유·로그 비밀값 제거·자식 실패 종료 코드 검증 포함 단위 테스트 총 7개 통과. start.cmd 최초 실행, 재실행 재사용, 기본 브라우저 실행, Chrome 로그인 화면 오류 0건 확인. 타입 검사 및 build 통과.

단계 9 / 실제 휴대폰 LAN 테스트 지원
- start-mobile.cmd 및 scripts/mobile-network.mjs: PC에 할당된 사설 IPv4를 찾아 휴대폰 URL 표시, 가상 어댑터보다 물리 네트워크 우선, --lan-ip로 명시 선택. 공인/루프백/미할당 IP를 임의로 선택하지 않음.

- 실제 LAN 주소의 Chrome 모바일/터치 390×844 검증: guestdemo 로그인 성공, 세션 API 재조회, 다른 Origin 403, 가로 넘침 없음, 페이지 오류 0건. 실제 휴대폰 하드웨어/공유기 방화벽 통과는 미검증.
- GPS는 휴대폰 LAN HTTP에서 제한되므로 테스트 계정과 추후 HTTPS 검증 범위를 11_모바일_테스트.txt에 구분. 포트포워딩/AWS/방화벽 규칙 자동 변경 없음.
- 주소 선택/사설 IP 판별 회귀 테스트 추가 후 단위 총 9개 및 타입 검사 통과.
