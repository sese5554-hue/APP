앱 테스트 피드백 반영 기록 (2026-11-20)

반영 내용
- 차량 일정과 일일 요금의 개별 저장 버튼 제거. 마지막 공개/변경 적용 버튼으로 함께 반영.
- 비공개 차량 관리에서 공개 전환 제공. 서버의 기존 공개 요건 검증 유지.
- 알림 설정 변경 시 즉시 저장. 저장 중 중복 변경 방지, 실패 안내.
- 채팅 검색 제거. 진행 중 거래만 보기와 안 읽은 대화 필터 제공.
- 다중 차량 관리 목록을 이름·상태·요금 중심으로 축약. 페이지 이동 단위 표시.
- 수신 채팅 및 취소/환불에 앱 내 즉시 알림과 해당 예약/대화 이동 제공. 설정에 따라 표시하며 자기 메시지는 제외.
- 환불 재확인에 실제 환불 결제 상태(완료/처리 중/실패/대상 없음) 안내. 호스트도 예약 상세에서 확인.
- 상단 프로필 사진 또는 이름 첫 글자 아바타 표시.
- 기존 예약 필수 인증 묶음 유지. 주소 관리에 동네 인증 목적 명시.
- 고객센터 문의 작성과 내 문의 내역 화면 분리. FAQ의 별도 검색 입력 제거.
- 새 예약 요청에 이동 동선 연결. 외관 분석 내부 버전/모드 텍스트 제거.
- 사진 8방향 누락 시 다음 단계 진행 방지. 공개/비공개 차량 세부사항 수정 후 관리 화면 복귀.
- 호스트와 게스트 날짜 선택에 월 달력 UI 제공. 수익 조회 월은 지우기 없는 선택 방식으로 변경.
- 일일 요금 상한을 1,000만 원으로 확대(서버와 화면). 추천 요금 즉시 표시.
- 차량 크기를 선택 버튼으로 변경. 편의 옵션 직접 입력·수정 지원(최대 20개, 각 60자).
- 차량 관리 카드에서 첫 후기 안내 제거.
- 지도 가격 말풍선에 위치 지시 침 추가 및 앵커 보정. 건물·상호명 확대 보기 제공.
- 대여 가능 기간 밖 예약은 기존 서버 검증으로 차단.
- 인수/반납 기록의 계기판 주행거리 입력을 사진보다 위로 이동.
- 인수 30분 전 제한은 실제 제출에만 적용. 확정 예약의 점검 초안은 미리 저장·복구 가능.

외부 연동 및 제한
- 실제 카카오페이·토스·계좌이체는 결제 공급자가 개발용이므로 아직 지원하지 않음.
- 앱을 닫은 상태의 기기 푸시는 공급자 미연동. 이번 알림은 접속 중 앱 내 실시간 알림임.
- 축소 지도의 건물/상호 표시는 지도 타일에 포함되어 있어 항상 표시하도록 바꾸지는 않음. 확대 보기 동선으로 보완.
- 채팅 정리는 필터 방식으로 반영. 자동 삭제 및 수동 영구 삭제는 추가하지 않음.
- 변경은 소스 및 웹 빌드에 반영. Android APK/Windows 설치본 재배포는 수행하지 않음.

검증
- 타입 검사, 단위 테스트 18개, 프로덕션 빌드 통과.
- MariaDB 통합 테스트 4개 통과. 시작 30분 이전 초안 저장과 실제 제출 차단 회귀 확인 추가.
- 모바일 브라우저 예약/승인/개발 결제 및 알림 자동 저장 검증.
