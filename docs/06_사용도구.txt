사용 도구와 도입 후보 기록

이번 문서 작업에서 실제 사용
- PowerShell: 저장소/파일 목록, UTF-8 원본 읽기, SVG text 추출, 실행 환경 확인.
- rg: 작업 파일과 저장소 지침 파일 검색.
- Git: 상태/원격/브랜치/이력 확인 및 요청된 커밋·push. 실제 결과는 최종 보고와 Git 이력으로 확인한다.
- Node.js v24.21.0: 외부 패키지 없는 문서 생성기와 검사기 실행 환경.
- npm.cmd 11.19.0: 버전 확인. PowerShell의 npm.ps1 실행 정책 제한을 확인하여 npm.cmd 사용. 패키지 설치는 하지 않음.
- Codex 파일 편집 도구: 문서 및 생성/검사 스크립트 작성.
- 확인 질문 도구: 문서 우선/즉시 앱 구현의 범위 확인 질문 전달. 현재 문서 산출물은 '지금은 구현하기 위한 프롬프트'라는 요청에 근거함.
- Sites 스킬 문서: 로컬 작업 절차 참고용 읽기만 수행. Sites 서비스 등록/호스팅/배포 도구는 사용하지 않음.

앱 구현 때 검토할 후보 (아직 설치/사용하지 않음)
- React/TypeScript 및 개발 빌드 도구: 모바일 웹 화면 구현.
- Node.js 서버 프레임워크 및 요청 검증 라이브러리: HTTP API, 인증, 오류 처리.
- MariaDB 서버와 Node.js connector: 실제 데이터 영속화 및 트랜잭션.
- 비밀번호 해시 라이브러리: 비밀번호 보호.
- 실시간 전송 도구: 인증된 채팅. WebSocket 또는 SSE+HTTP 중 요구에 맞춰 선택.
- 테스트 도구: 단위/HTTP/실제 MariaDB 통합 검증.
- Docker Compose: 선택 가능한 로컬 MariaDB 환경과 Ubuntu 실행 재현.

도구를 실제 도입할 때의 필수 기록
도구/정확한 버전 / 사용 목적 / 선정 이유 / 실제 사용 파일 / 실행 명령 / 결과 / 외부 설정 및 미검증 사항.
외부 서비스는 공급자·공식 문서·개발/운영 모드·필요 환경 변수 이름만 적고 비밀값은 기록하지 않는다.
