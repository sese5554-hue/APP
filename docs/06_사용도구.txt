사용 도구와 도입 후보 기록

이번 문서 작업에서 실제 사용
- PowerShell: 저장소/파일 목록, UTF-8 원본 읽기, SVG text 추출, 실행 환경 확인.
- rg: 작업 파일과 저장소 지침 파일 검색.
- Git: 상태/원격/브랜치/이력 확인 및 요청된 커밋·push. 실제 결과는 최종 보고와 Git 이력으로 확인한다.
- Node.js v24.21.0: 외부 패키지 없는 문서 생성기와 검사기 실행 환경.
- npm.cmd 11.19.0: 버전 확인. PowerShell의 npm.ps1 실행 정책 제한을 확인하여 npm.cmd 사용. 패키지 설치는 하지 않음.
- Codex 파일 편집 도구: 문서 및 생성/검사 스크립트 작성.
- 확인 질문 도구: 문서 우선/즉시 앱 구현의 범위 확인 질문 전달. 현재 문서 산출물은 '지금은 구현하기 위한 프롬프트'라는 요청에 근거함.
- Sites 스킬 문서: 로컬 작업 절차 참고용 읽기만 수행. Sites 서비스 등록/호스팅/배포 도구는 사용하지 않음.

앱 구현 때 검토할 후보 (아직 설치/사용하지 않음)
- React/TypeScript 및 개발 빌드 도구: 모바일 웹 화면 구현.
- Node.js 서버 프레임워크 및 요청 검증 라이브러리: HTTP API, 인증, 오류 처리.
- MariaDB 서버와 Node.js connector: 실제 데이터 영속화 및 트랜잭션.
- 비밀번호 해시 라이브러리: 비밀번호 보호.
- 실시간 전송 도구: 인증된 채팅. WebSocket 또는 SSE+HTTP 중 요구에 맞춰 선택.
- 테스트 도구: 단위/HTTP/실제 MariaDB 통합 검증.
- Docker Compose: 선택 가능한 로컬 MariaDB 환경과 Ubuntu 실행 재현.

도구를 실제 도입할 때의 필수 기록
도구/정확한 버전 / 사용 목적 / 선정 이유 / 실제 사용 파일 / 실행 명령 / 결과 / 외부 설정 및 미검증 사항.
외부 서비스는 공급자·공식 문서·개발/운영 모드·필요 환경 변수 이름만 적고 비밀값은 기록하지 않는다.

실제 앱 구현 시작 후 도입 (정확한 패치 버전은 package-lock.json)
- express 5.3.0: HTTP API. https://expressjs.com/en/5x/starter/installing/
- mariadb 3.5.5: MariaDB 연결 풀/트랜잭션. https://mariadb.com/docs/connectors/mariadb-connector-nodejs/connector-nodejs-promise-api
- react/react-dom 19.3.1, vite 8.3.8, @vitejs/plugin-react 6.3.0: TypeScript 반응형 웹 화면 및 번들. https://vite.dev/guide/
- zod 4.6.7: 공유 입력 검증. multer 2.5.0: 이미지 업로드. helmet 8.3.0: HTTP 보안 헤더. express-rate-limit 8.7.4: 인증 요청 제한. dotenv 18.0.10: 환경 로딩.
- typescript 7.0.2, tsx 4.23.15, @types 패키지: 타입 검사/개발 실행. Node.js native test/assert/scrypt: 테스트/암호화. 별도 테스트 프레임워크 및 비밀번호 패키지를 추가하지 않음.
- MariaDB Windows portable 11.4.5: 로컬 개발·통합 검증용으로 고정한 공식 아카이브. 다운로드 후 공식 sha256sums.txt와 비교. Ubuntu 구성은 compose.yaml의 MariaDB 11.4 계열 사용. https://archive.mariadb.org/mariadb-11.4.5/winx64-packages/
- npm 설치 및 tsx 테스트는 샌드박스 네트워크/Windows 사용자 정보 조회 제한으로 승격 실행. 시스템 실행 정책은 변경하지 않음.
- 도입 이후 테스트/실제 구현 상태는 08_실제구현.txt를 기준으로 확인. 위 '아직 설치/사용하지 않음' 항목은 최초 문서 작성 당시의 이력임.
- leaflet 1.9.4 + @types/leaflet 1.9.22: OpenStreetMap 확대·이동·가격 마커·픽업 위치 선택. https://leafletjs.com/reference-1.9.4.html
- @playwright/test 1.65.1: 실제 설치 Chrome을 headless로 실행하여 예약 흐름/52화면 렌더링·오류·가로 넘침 검증. 브라우저 새 다운로드는 하지 않음. https://playwright.dev/docs/test-webserver
- prettier 3.10.1: TypeScript/React/CSS/스크립트를 검토하기 쉽게 포맷.
- Dockerfile/compose.yaml/nginx/systemd: 향후 Ubuntu 운영을 위한 소스 예시 작성. 이번 Windows PC에 Docker가 없어 이미지 빌드/Ubuntu 설치는 미검증. AWS 도구와 배포는 사용하지 않음.
- 모바일 LAN 테스트: Node.js os.networkInterfaces 및 net.isIP로 PC의 실제 사설 IPv4 선택. 새 외부 패키지 없음. Vite host/Origin은 선택 주소로만 설정. Chrome 모바일/터치 모드로 LAN 로그인 검증. 공식 참고: https://vite.dev/config/server-options.html#server-host / https://developer.mozilla.org/en-US/docs/Web/API/Geolocation_API
- Inno Setup 6.7.4 ISCC: Windows EXE 생성/바로가기/제거 프로그램. 공식 배포 파일 게시자 서명 확인 후 .runtime/installer-tools에 설치. https://jrsoftware.org/inno-setup/downloads / https://jrsoftware.org/ishelp/topic_compilercmdline.htm
- Node.js24.21.0 Windows x64 아카이브: 공식 SHASUMS256와 비교 후 node.exe/라이선스를 번들. https://nodejs.org/download/release/v24.21.0/SHASUMS256.txt
- MariaDB11.4.5 Windows 패키지: 공식 sha256sums와 비교 후 데이터 없는 원본 바이너리 번들. Microsoft VC14.44.35211.0 공식 x64 재배포 패키지는 Authenticode Microsoft 게시자 확인 후 포함. https://aka.ms/vs/17/release/vc_redist.x64.exe
- npm ci --omit=dev --ignore-scripts: 소스 개발 node_modules와 분리해 설치본의 운영 패키지 생성. 전역 시스템 Node/npm을 제외한 PATH로 실제 번들 실행 검증. Windows 설치 관리자의 사용자별 등록은 테스트 후 해당 테스트 앱 제거로 정리했고, 데이터 보존 여부를 확인.
- 화면별 구현 설명: PowerShell·rg로 React/Express/SQL/테스트를 대조하고 Node.js fs/path/assert로 52개 TXT·목록 생성 및 실제 API·테이블·소스 앵커·코드 발췌 최신성을 검사. Prettier로 생성기 형식 정리. 새 패키지·외부 서비스 도입 없음.
- 종료 파일: Windows PowerShell Get-CimInstance로 실행 경로/부모/생성 시각 조회, taskkill로 검증한 앱 트리 종료, 기존 mariadb 커넥터로 datadir 확인 후 SHUTDOWN. Node.js child_process와 native test/assert 사용. 새 패키지 없음.
