앱 테스트 피드백 반영 기록 (2026-11-20)

반영
- 호스트 일정/요금 중복 저장 버튼 제거. 최종 공개/적용 버튼에서 함께 저장.
- 알림 설정 변경 즉시 서버 저장, 실패 안내와 중복 요청 방지.
- 비공개 차량 공개 전환, 다중 차량 요약 목록, 페이지 이동 문구 구체화.
- 채팅 검색 제거, 진행 중인 거래 필터. 거래 기록 자동 삭제는 적용하지 않음.
- 앱 내 채팅/환불 실시간 알림과 예약/대화 이동. 환불 상태 조회 결과 안내.
- 프로필 대체 아바타, 예약 필수 인증 묶음, 문의 내역 접근 개선.
- 월별 캘린더로 날짜 선택, 요금 상한 1,000만 원, 추천 요금 상시 노출.
- 차량 크기 버튼 선택, 추가 편의 옵션 입력, 수정 후 차량 관리 복귀.
- 지도 가격 마커 끝점 표시, 호스트의 중복 후기 문구 제거.
- 주행거리 입력 후 사진 순서. 인수 30분 전 제출 정책 유지, 이전에는 임시저장 허용.
- 예약 가능 기간의 서버 검증 유지 및 통합 테스트 보강.

별도 연동/검증 필요
- 현재 결제 공급자는 개발용이다. 카카오페이/토스/계좌이체 실결제 및 기기 푸시는 공급자 설정이 필요하다.
- 지도 축소 시 건물명 표시는 지도 타일 공급자의 데이터와 확대 수준에 따른다.
- 모바일 검증은 Chrome 모바일 크기 자동화이며 Android/iOS 실기기 검증과 구분한다.
- 최종 버튼의 일정/요금 저장은 순차 API 호출이다. 오류 시 안내되며 일부 저장이 먼저 완료될 수 있다.

검증
- 타입 검사, 단위 테스트 18개, 프로덕션 빌드 통과.
- MariaDB 통합 테스트 4개 통과.
- 모바일 브라우저: 인증/주소/오류 복귀/예약 승인 결제 흐름 확인.
- 전체 52화면과 피드백 추가 검증 결과는 .runtime/reports/feedback-results 참조.
최종 결과: 모바일 E2E 10개 모두 통과. 52개 화면 가로 넘침/런타임 오류 없음. 테스트 전용 서버에서만 API 요청 제한 제외.
